COPIE E COLE: cd VERSAO_1 && make && ./biblioteca
ou make && ./biblioteca

Cada livro deve ter estas informações:
- código
- título
- autor
- ano de publicação
- quantidade de exemplares disponíveis
- editora (novo)
- edição (novo)

Requisitos da Versão 1
- Cadastrar livro
- listar
- consultar por código
- emprestar
- devolver
- sair
- tratar entradas inválidas

-----------------------------------
Funcionalidades desenvolvidas:

- Sistema de multiplos usuarios
    - Login
    - Cadastro de usuario
    - Dos Usuarios comuns:
        - Listagem
        - Busca
        - Consulta (em andamento)
        - Emprestimo (em andamento)
        - Devolução (em andamento)
        - Editar/exluir conta (nova ideia)

    - Do Usuario proprietário:
        - Cadastro de novo livro
        - Edicao e exclusão de livro
        - Visualizar emprestimos (em andamento)

- Permanência de arquivos (no futuro)
- Alocação de memória (no futuro)
- Organização em múltiplos arquivos
- Desenvolvimento de bibliotecas personalizadas
