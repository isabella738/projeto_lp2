# projeto_lp2
Linguagem de Programação 2 com professor Antônio Louro  

Intruções de uso:  

Baixe o arquivo do projeto e descompacte-o. Tenha certeza de ter uma versão do compilador gcc instalada no computador (se for Windows, use MinGW). 
No terminal, vá até o diretório da versão desejada. Escreva os seguintes comandos no conforme o SO:
Em Linux:
- Compilar: make
- Executar: ./biblioteca

Em Windows:
- Compilar: mingw32-make
- Executar: abrir o executável criado na mesma pasta do diretório

Só é preciso compilar uma vez, a não ser que o utilizador faça mudanças no código fonte.
